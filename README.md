# 🧮 Calculadora de Funções em Python

Projeto desenvolvido em Python para calcular e resolver funções matemáticas e equações de forma prática via terminal.

---

### 🚀 Funcionalidades
- Resolução de equações de 1º e 2º grau.
- Operações de funções matemáticas.
- Tratamento de erros para entradas inválidas do usuário.

---

### 🛠️ Tecnologias Utilizadas
- **Python 3.x**
- Módulos nativos (`math`)
